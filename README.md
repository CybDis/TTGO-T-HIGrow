## What's New in v5.0.0 🎉

- **Native Home Assistant Integration**: Direct ESP32 to Home Assistant communication using ArduinoHA library
- **No External Dependencies**: Eliminates the need for Python autodiscovery scripts
- **Automatic Sensor Discovery**: All sensors automatically appear in Home Assistant
- **Enhanced Reliability**: Reduced failure points and improved performance
- **Backward Compatible**: Existing MQTT integrations continue to work
